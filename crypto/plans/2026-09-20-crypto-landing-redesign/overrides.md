# Logged overrides — landing redesign (2026-09-20)

1. **Macrostructure change, not a new vibe** — `Marquee Hero` (the only prior `.perfect-ui/log.json` entry) cannot repeat per Hard Rule 10. Picked `Bento Grid` for the body content (asymmetric interlocking cards for "what's included"), while keeping a full-bleed declarative hero moment — this is a genuine page-shape change (5 flat sections → 9, with a bento grid, pinned scroll section, and a dedicated chart section), not a same-shape reskin. Vibe/palette/typography/motion personality all stay locked from the original build; only macrostructure and visual density (3 → 5, more sections/cards) changed.

2. **Animated market-chart section is decorative, not real data** — per Hard Rule 3 (no fabricated metrics), the SVG chart in `market-chart.tsx` and the shader ridge in the hero are explicitly framed as illustrative motion ("Ілюстративна візуалізація руху ринку" in copy), generated by a deterministic seeded function — never presented as live/real market data, a specific asset's price, or a performance claim.

3. **No new 2D illustration assets generated** — no image-generation tool was available this session. Every visual that would previously have been a Phase-4 illustration (hero centerpiece, course tier cards, final-CTA background) is instead built from code (WebGL shader, inline SVG, CSS gradients) — which is what the user explicitly asked for, not a fallback compromise. The 6 now-unused JPGs were removed from `apps/web/public/`.

4. **Single-accent rule broken, then expanded site-wide (supersedes note 4 below as first written)** — user supplied a reference screenshot of a literal bull/bear (green/red) candlestick terminal. First pass scoped the two extra colors to one hero widget; user then explicitly asked for the full hero background (not "one little square") and for "the whole site" in these colors. `--accent` in `globals.css` was changed from gold (`41 54% 54%`) to the reference's teal-green (`162 66% 52%`, ex `#33D6A6`) — this is now the site-wide accent everywhere (buttons, links, icons, CTAs), not a scoped exception. A new `--bear` token (`3 75% 60%`, ex `#E5544D`) was added and is used ONLY inside chart visuals (hero backdrop candles) for the bearish/red half — never as a general UI color, since nothing in the request asked for red buttons or red text elsewhere. `app/components/effects/hero-market-backdrop.tsx` (full-bleed, replacing the old small square panel and the WebGL glass shader entirely) draws ~64 candles + a square graph-paper grid (`.chart-grid` utility) across the entire hero section. This is a deliberate, user-directed palette change from the original 2026-09-20-crypto-courses-landing lock, not an unintended drift.

5. **Lower half rebalanced (2026-09-21) — heading ladder + one trick per section** — user flagged that the page fell off a cliff after the first three sections (4.25rem H1 → 24px H2, no imagery, accent used only as a dot). Two changes were made rather than raising the lower half back to hero intensity, which would have flattened the page's rhythm. (a) A documented heading ladder now steps down one rung per section (hero 4.25 → bento 3 → how-it-works 2.25 → market 2 → courses 2 heavier → faq 1.5rem) and steps back **up** for the final CTA (2.25rem), since that is the closing ask; the map lives as a comment in `globals.css` and the sizes on the sections. (b) Each lower section got one bespoke visual instead of a shared "glass panel + line icon": scroll-triggered mini-demos + outlined step numerals + a sticky accent rail in `how-it-works`, a scroll-driven cursor with rider dots and turning-point pulses over the reused `.chart-grid` in `market-chart`, a featured middle tier with a hover equalizer and pointer tilt in `courses`, a square terminal-key toggle in `faq` (replacing the generic chevron; `faq-chevron.tsx` deleted for `toggle-plus.tsx`), and a breathing glow plus a 9%-opacity still of the hero candle tape in `final-cta`. The footer was deliberately left minimal.

6. **Two knowingly-taken liberties in note 5** — (a) the "цена" typewriter in step 2 of `how-it-works` types the **real** entry-tier price, which is why `page.tsx` now passes `courses` into that section; with no API response it types "цена: актуальная в боте" rather than inventing a figure, per Hard Rule 3. (b) The ticking number beside the market-chart headline is a client-side random walk around a fixed start value — under Hard Rule 3 it is labelled `демо-поток` on screen, carries no asset name, is `aria-hidden`, renders as a static value in the server HTML, and sits in the section whose own copy already frames the visuals as illustrative. It also uses `--bear` for down-ticks, which extends that token's "chart visuals only" scope from candles to the readout inside the same chart section — not to general UI.
