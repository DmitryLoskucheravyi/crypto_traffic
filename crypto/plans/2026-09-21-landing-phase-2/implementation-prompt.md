## 0. Контекст и жёсткие правила

Раздел 0 из промпта по «Пути курса» действует целиком: структура монорепо,
палитра через токены, `--bear` только в графиках, лестница заголовков,
`prefers-reduced-motion`, SSR-безопасность, никаких новых библиотек, RU на
лендинге / UA в админке. Ниже — только то, что специфично для этой фазы.

### Правило «никаких выдуманных метрик» — где оно бьёт по этим задачам

Три пункта из списка идей конфликтуют с этим правилом. Решения приняты такие,
их нужно соблюсти:

1. **Калькулятор дохода.** Не показывает прогноз. Показывает диапазон,
   рассчитанный по коэффициентам, которые владелец вводит в админке, и всегда
   сопровождается дисклеймером. Если коэффициенты не заполнены — секции нет.
   Никаких дефолтных «2–6% в месяц» в коде.
2. **Живой счётчик.** Никакого автоинкремента и фейкового «N человек сейчас на
   сайте». Выводятся только реальные числа, введённые в админке (или взятые из
   API, если появится реальный источник), с датой обновления. Не заполнено —
   полоса не рендерится.
3. **Тикер-разделитель.** Бегущая строка **не должна выглядеть как котировки
   реальных активов** — это прямое нарушение правила. Вместо `BTC 64 213 ▲`
   пускаем нейтральный контент: названия модулей, ключевые слова курса,
   короткие статусные строки. Если владелец всё же хочет цифровой вид —
   значения помечаются как демо-поток, ровно как это уже сделано у бегущего
   числа в `market-chart.tsx`.

## 2. Бэкенд: общая часть

Один новый модуль в `apps/api/src/`, по образцу `courses/`:

### 2.1 `site-content/` — синглтон настроек

Одна запись в коллекции (`key: 'default'`, уникальный индекс). Хранит всё, что
не является списком:

```ts
{
  calculator: {
    enabled: boolean;
    amountMin: number;          // левый край слайдера
    amountMax: number;
    amountStep: number;
    currency: string;           // 'USD'
    horizonMonths: number;      // горизонт, на который считаем
    tiers: Array<{              // коэффициенты по уровню курса
      tier: 'basic' | 'medium' | 'advanced';
      lowPct: number;           // нижняя граница диапазона, % за горизонт
      highPct: number;          // верхняя граница
    }>;
    disclaimer: string;         // обязательный, пустым не сохраняется
  };
  counters: {
    enabled: boolean;
    studentsTotal: number | null;
    seatsLeft: number | null;
    note: string;               // «мест на этой неделе» и т.п.
    updatedAt: string;          // ставится сервером при сохранении
  };
  comparison: {
    enabled: boolean;
    leftTitle: string;          // «Сам по видео с YouTube»
    rightTitle: string;         // «Курс»
    rows: Array<{ label: string; left: string; right: string }>;
  };
  lessonPreview: {
    enabled: boolean;
    title: string;
    description: string;
    mediaUrl: string;           // путь или внешний URL
    mediaAlt: string;
    isIllustrative: boolean;    // true → на картинке подпись «иллюстрация»
  };
  ticker: {
    enabled: boolean;
    items: string[];            // строки бегущей ленты
  };
}
```

Эндпоинты: `GET /api/site-content` (публичный, отдаёт только блоки с
`enabled: true`), `GET /api/admin/site-content` и `PUT /api/admin/site-content`
(оба под `JwtAuthGuard`). DTO с `class-validator`, вложенные объекты — через
`@ValidateNested` + `@Type`.

### 2.2 Загрузка файлов

Загрузки файлов в API сейчас нет. **Не строить её в этой фазе.** Поле
`mediaUrl` — строка: либо путь к файлу, положенному в `apps/web/public/`, либо
внешний URL. Картинка для прев'ю уроку уже сгенерирована и лежит как
`/lesson-preview.png` — она иллюстративная, поэтому по умолчанию
`isIllustrative: true`. Если используется внешний URL — добавить
домен в `images.remotePatterns` в `apps/web/next.config.js`, иначе `next/image`
упадёт. В админке рядом с полем — подсказка об этом на украинском.

## 4. Новые секции лендинга

Общее для всех: данные тянутся в `app/page.tsx` (уже `force-dynamic`) одним
`Promise.all`, каждый геттер в `app/lib/api.ts` с `try/catch` и безопасным
пустым значением. **Любая секция без данных не рендерится** — никаких
заглушек «скоро здесь будет».

### 4.1 `income-calculator.tsx` — между Bento и HowItWorks

- Слайдер «Сколько готовы вложить»: нативный `<input type="range">`,
  стилизованный под терминал (трек `bg-ink/10`, заполнение и бегунок —
  `accent`, квадратный бегунок, не круглый). Значение — крупное моноширинное
  число, форматирование `Intl.NumberFormat('ru-RU')`.
- Выпадающий список уровня курса — из реальных активных курсов (`getCourses()`
  уже вызывается на странице), а не из константы.
- Результат: диапазон «от X до Y» за `horizonMonths` месяцев, считается как
  `amount * (1 + pct/100)` по обеим границам выбранного уровня. Числа
  анимируются компонентом `<CountUp>` из раздела 5.2.
- Дисклеймер выводится **всегда**, не под спойлером, `text-ink-muted text-xs`,
  прямо под результатом.
- Кнопка «Смотреть уровни» — плавный скролл к `#courses` (у секции курсов
  должен появиться `id`).
- Вся арифметика — на клиенте, без обращений к API при движении слайдера.
- Реализация: `'use client'`, состояние в `useState`, пересчёт в `useMemo`.

### 4.2 `comparison.tsx` — после MarketChart

- Две колонки: слева `leftTitle`, справа `rightTitle`, под ними строки из
  `rows`.
- Эстетика терминального diff: моноширинный шрифт, префикс `-` у левой
  колонки, `+` у правой.
- **Красный не использовать** (правило про `--bear`). Левая колонка —
  `text-ink-muted`, правая — `text-ink` с акцентным префиксом.
- Появление: построчный stagger при входе во вьюпорт, задержка 40ms на строку.
- Мобильный: строки складываются в карточки «пункт → слева / справа».

### 4.3 `lesson-preview.tsx` — после Comparison

- Свёрнутое состояние: заголовок + кнопка «Посмотреть фрагмент урока».
- Развёрнутое: изображение (`next/image`, `sizes`, ленивое) + описание.
- Анимация высоты через framer-motion (`height: 0 → auto`), `aria-expanded` /
  `aria-controls`.
- Если `isIllustrative === true` — поверх нижнего края картинки подпись
  «Иллюстрация», моношрифт, полупрозрачная плашка.
- Картинка не грузится, пока блок свёрнут (рендерить `<Image>` только в
  раскрытом состоянии).

### 4.4 `counters-strip.tsx` — прямо перед Courses

- Узкая полоса, `border-y border-ink/10`, без крупного заголовка.
- Два-три числа: `studentsTotal`, `seatsLeft`, плюс `note` мелким шрифтом.
  Каждое — через `<CountUp>`, один раз при появлении, от 0 до реального
  значения.
- Под числами — «обновлено DD.MM.YYYY» из `counters.updatedAt`, `text-xs`.
  Это и есть честность: видно, что число статичное и когда его поставили.
- `null` в поле → это число не выводится. Оба `null` → полосы нет.

## 5. Сквозные визуальные фичи

### 5.1 Кастомный курсор-прицел

- Компонент `app/components/effects/crosshair-cursor.tsx`, подключается один
  раз в `app/layout.tsx`.
- Рендерится только при `matchMedia('(pointer: fine)')` и отсутствии
  `prefers-reduced-motion`. На тач-устройствах не монтируется вообще.
- Вид: две линии 1px (горизонталь + вертикаль, по 14px) и квадрат 18×18 с
  границей `ink/25`. При наведении на интерактивный элемент (`a`, `button`,
  `[role="button"]`, `[data-cursor="target"]`) квадрат увеличивается до 28px и
  красится в `accent`.
- Позиция — `transform: translate3d()` в `requestAnimationFrame`, слушатель
  `pointermove` с `{ passive: true }`. Никаких `left/top`.
- `body { cursor: none }` включается тем же условием, что и монтирование
  компонента — иначе на тач-устройствах и при reduced-motion курсор пропадёт
  совсем. Фокусные обводки (`:focus-visible`) не трогать.

### 5.2 `<CountUp>` — прокрутка цифр

- `app/components/ui/count-up.tsx`: пропсы `value`, `duration = 800`,
  `format?`.
- Запуск по `IntersectionObserver`, один раз. Анимация — `requestAnimationFrame`
  + `easeOutCubic`, не `setInterval`.
- **В серверном HTML сразу лежит финальное значение** (для SEO и AT), анимация
  только перезаписывает текст после монтирования.
- `prefers-reduced-motion` → значение выводится сразу.
- Использовать в: калькуляторе, `counters-strip`, ценах в `courses.tsx`.

### 5.3 Зерно (grain)

- Готовый тайл лежит в `apps/web/public/grain.png`. Утилита `.grain` в
  `globals.css`: отдельный `fixed inset-0 pointer-events-none` слой с
  `background-image: url('/grain.png')` и `background-repeat: repeat`. Если
  тайл окажется нешовным — заменить на data-URI SVG `feTurbulence`
  (`baseFrequency ~0.8`, `numOctaves 3`), результат тот же, веса меньше.
- Прозрачность 2–3%, `z-index` ниже модалок, но выше секций.
- Проверить, что слой не перехватывает клики и не ломает `backdrop-filter` в
  `.glass-panel`.

### 5.4 Тикер-разделитель

- `app/components/sections/ticker-divider.tsx`, максимум два на странице.
- Полоса высотой ~40px, `border-y border-ink/10`, моношрифт `text-xs`,
  `uppercase`, `tracking-[0.2em]`, `text-ink-muted`.
- Бесконечная лента — переиспользовать приём из `trust-strip.tsx`: набор
  дублируется дважды, `animate-marquee` со сдвигом на -50%, шва не видно.
  Скорость медленнее, чем у ленты иконок (60–80s на цикл).
- Контент — `ticker.items` из админки. Разделитель между элементами — точка
  `bg-accent` 4×4.
- `prefers-reduced-motion` → лента не едет, показывается первый экран строк.

## 6. Анимации

### 6.1 Магнитные кнопки

- Хук `app/lib/use-magnetic.ts`: возвращает `ref` и обработчики.
- Радиус срабатывания 24px от границы элемента, максимальное смещение 8px,
  возврат — пружина framer-motion (`stiffness: 250, damping: 20`).
- `pointermove` слушается **на самом элементе**, а не на `window`.
- Отключено при `(pointer: coarse)` и `prefers-reduced-motion`.
- Применяется только к главным CTA: кнопка в Hero, кнопки в карточках курсов,
  кнопка в FinalCta. Не вешать на все ссылки.

### 6.2 Text scramble

- Компонент `app/components/ui/scramble-text.tsx`.
- **Строго два места на странице:** H1 в Hero и H2 в FinalCta. Больше — не
  добавлять, это подпись сцены, а не украшение каждого блока.
- 200–300ms, символы подмешиваются из набора `A-Z0-9/\\<>*#` (латиница +
  символы; кириллицу не мешать — на кириллическом тексте это читается как
  опечатка).
- Финальный текст присутствует в DOM с сервера. Анимируемый слой —
  `aria-hidden`, рядом `sr-only` с настоящим текстом; либо `aria-label` на
  контейнере. Проверить скринридером, что заголовок читается один раз.
- Запуск: Hero — при монтировании, FinalCta — при входе во вьюпорт, один раз.
- `prefers-reduced-motion` → статичный текст.

### 6.3 Посимвольная печать цен

- В `courses.tsx` цена появляется посимвольно (30ms на символ) при входе
  карточки во вьюпорт.
- Значение — реальное, из API. В серверном HTML — сразу финальное.
- Не совмещать с `<CountUp>` на одном и том же числе: цена либо печатается,
  либо прокручивается. Для цен выбрана печать, для счётчиков — прокрутка.

### 6.4 Полоса прогресса скролла

- `app/components/effects/scroll-progress.tsx`, подключается в `layout.tsx`.
- `fixed top-0 left-0 right-0 h-[2px] z-50`, `bg-accent`,
  `transform-origin: left`, `scaleX` от `useScroll().scrollYProgress` через
  `motion.div` — без ручных слушателей скролла.
- Учесть `lenis`: прогресс берётся из того же источника, что и остальной
  скролл, иначе на инерции полоса будет дёргаться.
- При `prefers-reduced-motion` полосу оставить (это индикатор, а не
  декоративное движение), но убрать сглаживание `useSpring`.

## 8. Критерии готовности

- [ ] `npx tsc --noEmit` и `npm run build` зелёные в `apps/web`, `apps/api`, `apps/admin`.
- [ ] API недоступен → лендинг рендерится, новых секций просто нет, консоль чистая.
- [ ] Каждый блок выключается своим `enabled` из админки и исчезает со страницы.
- [ ] Ни одного захардкоженного числа или процента в коде `apps/web`.
- [ ] Калькулятор показывает дисклеймер всегда; без коэффициентов секции нет.
- [ ] Счётчики показывают дату обновления; нет автоинкремента.
- [ ] Бегущая строка не имитирует котировки реальных активов.
- [ ] Красный (`--bear`) не появился за пределами графиковых секций.
- [ ] `prefers-reduced-motion: reduce`: нет курсора, нет магнита, нет scramble,
      нет бегущей ленты, счётчики и цены статичны, прогресс-бар без сглаживания.
- [ ] Тач-устройство: кастомный курсор не смонтирован, `cursor: none` не применён,
      магнитные кнопки работают как обычные.
- [ ] Клавиатура: все раскрывающиеся блоки доступны, `:focus-visible` виден везде.
- [ ] Lighthouse на мобильном не просел больше чем на 5 пунктов по Performance
      относительно текущей страницы.

## 9. Чего не делать

- Не добавлять библиотеки: каруселей, таблиц, анимаций чисел, кастомных
  курсоров. Всё перечисленное делается на `framer-motion` + `gsap`, которые уже
  стоят.
- Не строить загрузку файлов в API — в этой фазе только URL/пути.
- Не ставить `TickerDivider` между каждой парой секций.
- Не применять scramble больше чем в двух местах.
- Не вешать магнит на все кнопки подряд.
- Не рисовать фейковую «живость»: онлайн-счётчики, растущие числа,
  псевдо-котировки реальных монет.
- Секцию отзывов не делать — она снята с плана по решению владельца.
- Не менять существующие секции ради единообразия — эта фаза только добавляет.
