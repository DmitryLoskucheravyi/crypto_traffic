## 0. Контекст проекта — прочитать до первой правки

Монорепозиторий `crypto/`:

|---|---|---|---|

| `apps/admin` | Next.js, TS, Tailwind | — | админка (UA) |
| `apps/bot` | Telegram-бот | 3033 | — |

Жёсткие правила, действующие в этом репозитории (см.
`plans/2026-09-20-crypto-landing-redesign/overrides.md`):

1. **Никаких выдуманных метрик.** Все числа на лендинге — либо из API/админки,
   либо явно помечены как иллюстративные. Количество уроков в этапе — реальное,
   вводится в админке. Не хардкодить «7 этапов, 5 уроков» в коде.
2. **Палитра только через токены** `globals.css`: `--bg`, `--surface`, `--ink`,
   `--ink-muted`, `--accent` (изумрудный `162 66% 52%`). Токен `--bear`
   (красный) разрешён **только внутри графиковых визуалов** — в этой секции он
   не используется.
3. **Референс фиолетовый — палитру не копировать.** Из скриншота берётся
   композиция и структура карточки, цвет остаётся изумрудным.
4. **Лестница заголовков** задокументирована комментарием в `globals.css`:
   каждая секция на ступень ниже предыдущей. Новая секция должна встроиться в
   эту лестницу, а не выбиваться — посмотреть комментарий и взять ступень
   уровня `how-it-works`.
5. **`prefers-reduced-motion`** обрабатывается в каждой анимации.
6. **SSR-безопасность:** никакого `window` вне `useEffect`, никакого
   `Math.random()` в рендере (есть `app/lib/seeded-random.ts`).
7. Зависимости уже есть: `framer-motion`, `gsap` + `ScrollTrigger`, `lenis`.
   **Новые библиотеки не добавлять.**
8. Тексты лендинга — русский, статика живёт в `app/lib/content.ts`. Интерфейс
   админки — украинский (см. существующие экраны).

## 1. Что именно делаем

Секция «Путь курса»: вертикальный маршрут по этапам обучения. По центру —
изометрическая иллюстрация-дорога, по бокам в шахматном порядке карточки
этапов. На карточке: номер этапа, название, чипы «N уроков» и «Тестирование»,
кнопка «Структура модуля», раскрывающая список тем.

**Этапов шесть.** Ассеты уже сгенерированы и лежат в `apps/web/public/`:

| Файл | Что это |
|---|---|
| `roadmap-path.jpg` | цельная изометрическая дорога, вертикаль ~2:3 — фон центральной колонки |
| `roadmap-1.png` … `roadmap-6.png` | шесть изометрических объектов на прозрачном фоне, ~576×576 — по одному на этап |

Новые изображения в этой задаче не генерируются.

Секция управляется из админки целиком: количество этапов, их порядок,
названия, число уроков, наличие тестирования и список тем внутри этапа.

## 2. Бэкенд (`apps/api`)

Новый модуль `apps/api/src/roadmap/`, скопировать структуру существующего
`apps/api/src/courses/` (schema / service / controller / dto / module) и
зарегистрировать в `apps/api/src/app.module.ts`.

### Схема `roadmap-stage.schema.ts`

```ts
@Schema({ timestamps: true })
export class RoadmapStage extends Document {
  @Prop({ required: true, min: 1 }) order: number;       // позиция, 1..N
  @Prop({ required: true }) title: string;               // «Введение в рынки»
  @Prop({ required: true, min: 0 }) lessonsCount: number;
  @Prop({ required: true, default: false }) hasTest: boolean;
  @Prop() summary?: string;                              // 1-2 предложения, опционально
  @Prop({ type: [String], default: [] }) modules: string[]; // темы внутри этапа
  @Prop() imageUrl?: string;                             // '/roadmap-3.png'
  @Prop({ required: true, default: true }) active: boolean;
}
```

Индекс по `order` — уникальный.

### Эндпоинты

| Метод | Путь | Гард | Возвращает |
|---|---|---|---|
| GET | `/api/roadmap` | — | активные этапы, отсортированные по `order` |
| GET | `/api/admin/roadmap` | `JwtAuthGuard` | все этапы, включая неактивные |
| POST | `/api/admin/roadmap` | `JwtAuthGuard` | создать этап |
| PUT | `/api/admin/roadmap/:id` | `JwtAuthGuard` | обновить этап |
| DELETE | `/api/admin/roadmap/:id` | `JwtAuthGuard` | удалить этап |
| PATCH | `/api/admin/roadmap/reorder` | `JwtAuthGuard` | принять `[{id, order}]` и сохранить транзакцией |

Админские маршруты вынести в отдельный контроллер
`@Controller('admin/roadmap')` внутри модуля roadmap — не раздувать
существующий `admin.controller.ts`. Гард берётся оттуда же
(`../admin/jwt-auth.guard`), как это уже сделано для курсов.

DTO — `class-validator`, по образцу `upsert-course.dto.ts`. Глобальный
`ValidationPipe({ whitelist: true })` уже включён в `main.ts`.

### Сидинг

Не сидировать выдуманные этапы. Пустая коллекция — валидное состояние: секция
на лендинге просто не рендерится, в админке показывается пустой список с
кнопкой «Додати етап».

## 4. Фронтенд (`apps/web`)

### Данные

- В `app/lib/api.ts` добавить тип `RoadmapStage` и `getRoadmapStages()` по
  образцу `getCourses()`: `cache: 'no-store'`, `try/catch`, при ошибке —
  пустой массив (страница уже `force-dynamic`).
- В `app/page.tsx` дописать вызов в существующий `Promise.all` и передать
  массив пропом в секцию.
- **Если активных этапов нет — секция не рендерится вообще** (`if (!stages.length) return null`).

### Размещение

В `app/page.tsx` между `HowItWorks` и `MarketChart`:

```
Hero → TrustStrip → Bento → HowItWorks → Roadmap → MarketChart → Courses → Faq → FinalCta → Footer
```

### Файлы

- `app/components/sections/roadmap.tsx` — секция.
- `app/components/sections/roadmap-card.tsx` — карточка этапа (клиентская,
  держит состояние раскрытого списка тем).
- Статические подписи («Этап», «уроков», «Тестирование», «Структура модуля»,
  заголовок и подзаголовок секции) — в `app/lib/content.ts`, ключ `roadmap`.
  Склонение «урок/урока/уроков» — маленький хелпер, не библиотека.

### Раскладка

**Десктоп (md+):**
- Контейнер `max-w-container`, три колонки: карточка слева — иллюстрация по
  центру — карточка справа. Проще всего сеткой `grid-cols-[1fr_auto_1fr]`, где
  карточка занимает свою колонку, а пустая сторона — просто пустая ячейка.
- Этапы чередуются: 1-й справа, 2-й слева, 3-й справа… (как на референсе).
- Иллюстрация `/roadmap-path.jpg` — `next/image` с `sizes`, абсолютным слоем
  позади центральной колонки, `-z-10` относительно карточек,
  `priority={false}`. Пропорции исходника ~2:3, вписывать по высоте секции.
- Карточки не должны наезжать на иллюстрацию: минимальный зазор 24px.

**Мобильный (<md):**
- Одна колонка, карточки подряд.
- Большая иллюстрация скрыта (`hidden md:block`). Вместо неё — вертикальная
  линия-рейка слева (1px, `bg-ink/10`) с точкой-маркером у каждого этапа;
  точка подсвечивается `accent`, когда карточка входит во вьюпорт.

### Карточка

- Панель: `bg-surface`, `border border-ink/10`, `rounded-xl`, при наведении
  подъём на 2px + граница `border-accent/30` (переход 300ms).
- Строка «Этап N» — моношрифт, `text-xs`, `uppercase`, `tracking-[0.2em]`,
  `text-ink-muted`.
- Заголовок — `font-display`, `uppercase`, ступень лестницы заголовков на один
  рунг ниже заголовка секции.
- Объект этапа (`imageUrl`) — `next/image` 96×96 в углу карточки, прозрачный
  PNG кладётся прямо на панель. Пустое поле — карточка без картинки, раскладка
  не ломается.
- Чипы: «N уроков» и «Тестирование» — моношрифт `text-[11px]`, `uppercase`,
  перед каждым квадратная точка 6×6 `bg-accent`. Чип «Тестирование»
  рендерится только при `hasTest === true`.
- Кнопка «Структура модуля» — во всю ширину, `border border-ink/15`,
  `rounded-lg`, моношрифт, `uppercase`, `tracking-wide`. При клике —
  **раскрывающийся список внутри карточки** (не модалка): `modules.map()`
  нумерованным списком, анимация высоты через framer-motion
  (`initial/animate height: 0 → auto`). Кнопка получает `aria-expanded` и
  `aria-controls`; список — `id`.
- Если `modules` пуст — кнопка не рендерится.
- `summary`, если заполнен, — абзац `text-ink-muted text-sm` под заголовком.

### Анимация

- Карточки: `fadeUp` из `app/lib/motion.ts` + сдвиг по X в сторону своего края
  (левые из `x: -24`, правые из `x: 24`), `whileInView`, `once: true`,
  `margin: '-100px'`.
- Маршрут: поверх иллюстрации лежит SVG-путь (`<path>`, `stroke` =
  `hsl(var(--accent))`, `strokeWidth` 2, свечение через `drop-shadow`), который
  **рисуется по мере скролла** — GSAP ScrollTrigger со `scrub: 1`, техника та
  же, что в `market-chart.tsx`: `strokeDasharray = length`,
  `strokeDashoffset` от `length` до 0. Путь рисуется вручную под геометрию
  сгенерированной иллюстрации.
- Точки-узлы на пути: по одной напротив каждого этапа, `scale` 0→1 + вспышка
  свечения в момент, когда соответствующая карточка входит во вьюпорт.
- Опционально, если хорошо ляжет: подпись «СТАРТ» вдоль начала пути через SVG
  `textPath`. Английское «START POINT» с референса не копировать — лендинг
  русскоязычный.
- При `prefers-reduced-motion` — ничего из перечисленного: путь отрисован
  целиком, карточки без сдвига, точки статичны.

### Производительность

- Одна ScrollTrigger-таймлиния на секцию, не по одной на карточку.
- Всё через `gsap.context()` с `ctx.revert()` в cleanup — как в
  `market-chart.tsx`.
- Иллюстрация в WebP/AVIF, ширина не больше 1200px, вес ≤ 400 КБ.

## 5. Критерии готовности

- [ ] `npx tsc --noEmit` и `npm run build` в `apps/web` проходят.
- [ ] `npm run build` в `apps/api` и `apps/admin` проходит.
- [ ] Этап, добавленный в админке, появляется на лендинге после перезагрузки.
- [ ] Пустая коллекция → секции на странице нет, ошибок в консоли нет.
- [ ] API недоступен → страница рендерится без секции, без исключений.
- [ ] Мобильная раскладка: одна колонка, иллюстрация скрыта, рейка работает.
- [ ] `prefers-reduced-motion: reduce` → статичная секция.
- [ ] Клавиатура: кнопка «Структура модуля» фокусируется, раскрывает список,
      `aria-expanded` меняется.
- [ ] В коде нет ни одного захардкоженного этапа, названия или числа уроков.
      Единственное исключение — список доступных файлов картинок для
      выпадающего списка в админке.
- [ ] В секции не использованы `--bear`, фиолетовый и любые цвета вне токенов.
